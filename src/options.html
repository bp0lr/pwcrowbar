      Tips

      • Domain regex is matched against the requested asset host (e.g. cdn.example.com).
      • File regex is matched against the full request path plus query (e.g. /js/app.js?build=1).
      • Redirect rules block navigations whose final URL matches the regex you provide.
      • Chrome uses the RE2 engine. Avoid lookbehinds and other unsupported constructs.
      • Test patterns in an external regex tester before saving to avoid silent skips.
